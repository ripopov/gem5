# Appendix B: Memory-System Code Atlas

This appendix will provide a directory-level map of gem5's memory subsystem source tree.
It will cover `src/mem/cache/`, `src/mem/ruby/system/`, `src/mem/ruby/protocol/`, `src/mem/ruby/network/`, `src/mem/`, and the stdlib Python components under `src/python/gem5/components/cachehierarchies/` and `src/python/gem5/components/memory/`.
Each directory will get a brief description of its role, key files, and which chapters reference it.
This serves as a quick-lookup reference so readers can orient themselves in the source tree during any chapter.
