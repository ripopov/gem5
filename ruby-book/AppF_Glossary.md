# Appendix F: Glossary and Notation

This appendix will provide a single-source glossary enforcing one term per concept across the entire book.
It will map prose terms (e.g., "cache line", "flit", "message buffer") to their gem5 class and file names (e.g., `CacheBlk`, `flit`, `MessageBuffer`).
A notation table will define all symbols, abbreviations, and conventions used in diagrams, equations, and code listings throughout the book.
This serves as the canonical reference for terminology consistency, as required by the book's writing guidelines.
