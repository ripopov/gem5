# Appendix D: Garnet Parameter and Topology Reference

This appendix will provide a reference table for Garnet's configurable parameters: router latency, link width, VC count, buffer depth, and routing algorithm selection.
It will document the topology construction API used by `configs/topologies/*.py` and how custom topologies connect routers, links, and external nodes.
Key command-line flags from `configs/network/Network.py` will be listed with their effects on simulation behavior.
This serves as the go-to reference when readers are configuring Garnet experiments in Chapters 11 and 12.
